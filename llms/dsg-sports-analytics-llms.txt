# DSG Sports Analytics

> DSG Sports Analytics GmbH (trading as Data Sports Group), Berlin, Germany, operates the DSG Sports
> Data API - a read-only HTTP feed of live scores, statistics, historical results, fixtures, player
> and team records, news and betting odds across 85 sports. The API is credentialed and sales-quoted;
> its reference documentation is fully public at dsg-api.com.

This file was GENERATED by API Evangelist from the provider's public documentation and from the
artifacts in this repository. It is not published by DSG Sports Analytics.

## At a glance

- Base URL: `https://dsg-api.com` — per-request form `https://dsg-api.com/clients/{client_name}/{sport}/{operation}`
- API version: 3.0 (individual operations still carry v2 badges)
- Transport: HTTPS only, `GET` only — the published surface is entirely read-only
- Formats: XML by default; JSON with `&ftype=json` or `&ftype=json_array`
- Auth: two required query parameters, `client` and `authkey`, plus an account password and a per-domain allowlist
- Rate limit: 10,000 calls per hour across the whole account, reset at :00 — no rate-limit response headers
- Surface: 85 sports x 46 operation families = 1607 documented operations
- No OpenAPI, AsyncAPI, GraphQL, gRPC or WSDL is published; no MCP server; no agent card; no SDKs
